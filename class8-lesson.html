Linear Equations in One Variable

Discover unknown values through simple explanations and interactive examples.

📘

What is a Linear Equation?

A linear equation is a mathematical statement that contains an unknown value, usually represented by a letter such as x.

Example:
2x + 3 = 11

Here, x is the unknown value. Our goal is to find the value of x that makes the equation true.

🎯

What Will We Learn?

  • Understand variables and unknown values.
  • Understand the equality sign.
  • Solve simple linear equations step by step.
  • Verify the answer by substitution.
⚖️

An Equation Is Like a Balance

Imagine a weighing balance. Both sides must have equal weight to remain balanced. An equation works in the same way.

LEFT SIDE
x + 3
=
RIGHT SIDE
11
💡 Whatever operation we perform on one side, we must perform on the other side to maintain equality.
🧮

Let's Solve an Equation!

Find the value of x in the equation below.

2x + 3 = 11
STEP 1

Start with the equation

2x + 3 = 11

We need to isolate x by removing the extra numbers around it.

1 / 4
🎉 We found the answer!
x = 4

The value of x is 4. Let's verify: 2 × 4 + 3 = 11. Therefore, our answer is correct!

Teacher's Classroom Tip

Use a physical balance or draw two equal groups on the board. Ask students what happens when the same quantity is removed from both sides. This helps them understand why equations must remain balanced.
